# SOARING RACING — V3 (BITFSD-inspired layout)

基于车队实拍照片制作的原创排版版本。参考 BITFSD 首页的信息结构：大幅轮播、车队简介、赛车重点展示、新闻列表、资源入口及页脚。未复制对方源代码、图片或品牌视觉。

## 部署

1. 解压 ZIP，把内部的 `index.html`, `styles.css`, `script.js`, `assets/` 上传到原 GitHub 仓库根目录。不要套一层文件夹。
2. Commit 到 `main` 分支，EdgeOne Makers 已连接仓库则会自动构建。
3. 查看部署日志和预览。
4. 正式面向中国大陆公开访问时，需要配置独立域名，并实际测试三大运营商网络。

## 首页栏目

1. 三张实拍图片自动轮播（支持前后按钮和小点切换）
2. 关于我们
3. 赛车项目
4. 赛事动态（新闻列表 + 精选照片，文章尚无外链）
5. 赛道相册
6. 加入车队（招新）
7. 文创 / 活动 / 推文入口（未添加虚构商品价格）
8. 合作伙伴与联系

## 修改内容

- 修改主色：`styles.css` 最顶部 `:root` 中的 `--blue`、`--violet`、`--bg`。
- 修改首页图片：`index.html` 中 `--hero-image:url('assets/hero-racing.webp')` 等三处。
- 添加正式新闻：替换 `.news-list` 中每个 `<article>` 的文字，发布真实文章链接后再把容器改成可点击链接。
- 文创上架：需要补充实物照片、真实商品信息、咨询/支付渠道。当前仅为展示区域。
- 联系方式：搜索 `官方邮箱 / 公众号 / 报名入口：待补充`。
- 官方 logo：`assets/soaring-logo.png`。
