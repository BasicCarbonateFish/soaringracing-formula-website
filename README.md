# 翱翔方程式官网 V4 高保真设计原型

## 这是什么
七页完整静态网页高保真**设计原型**，未部署，也不替换现有 V3 网站。首页严格按「赛车大图轮播 → 车队简介 → 最新动态 → 合作伙伴」顺序。深色首页/招商页，其余浅色易读内容页。

## 查看方法
1. 解压 ZIP。
2. 双击 `index.html` 即可在浏览器查看首页。
3. 点击顶栏导航查看六个独立栏目。也可单独打开 `about.html`、`cars.html`、`news.html`、`join.html`、`community.html`、`partners.html`。
4. 缩窄浏览器窗口可查看移动端布局。

## 文件
- `index.html`：首页；`about.html`：关于翱翔；`cars.html`：赛车技术；`news.html`：新闻；`join.html`：招新；`community.html`：文化、文创；`partners.html`：合作伙伴。
- `styles.css`：所有页面的视觉设计；`script.js`：导航、轮播和新闻分类等原型交互；`assets/`：上传的赛车与团队照片经之前 V3 整理压缩的素材。
- `v4-overview.jpg`：七页设计总览（若该文件存在）。

## 内容状态
- 这是排版和视觉审阅稿，新闻、活动、商品为明确标识的原型演示，不是正式公告、售卖或已核实的赛果。
- 已知合作伙伴展示文本基于用户此前提供的信息，公开合作身份、LOGO、年份等发布前仍须确认。
- 某些赛事图片自带主办方标识、水印；对外正式发布需核实传播授权。
- 图片、品牌和联系人资料发布前还应完成校对和授权确认。
